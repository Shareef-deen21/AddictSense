---

## Project Overview

AddictSense is a full-stack machine learning web application that classifies a user's social media addiction level across four severity categories Low, Moderate, High, and Severe, based on eleven behavioural and psychological input features. The system integrates SHAP (SHapley Additive exPlanations) explainability to provide transparent, per-user feature attribution charts alongside personalised behavioural recommendations, making the prediction interpretable and actionable for non-technical end users.

The application is built using Python and Streamlit and is deployed publicly on Streamlit Community Cloud.

## Key Features

- Multi-level addiction classification across four severity levels: Low, Moderate, High, and Severe
- Five trained ML classifiers available for comparison: Random Forest, XGBoost, LightGBM, CatBoost, and Logistic Regression
- SHAP explainability with per-user horizontal bar charts showing feature contributions
- Personalised clinical recommendations and lifestyle alternatives based on SHAP risk features
- Model performance metrics displayed per selected algorithm (Accuracy, F1 Score, ROC-AUC)
- Authenticated multi-page Streamlit application with session state management
- Progressive disclosure result panel with four tabs: Probabilities, Why This?, Advice, and Alternatives

## Model Performance

| Model | Accuracy | F1 Score | ROC-AUC |
|---|---|---|---|
| Random Forest (Production) | 98.58% | 0.9858 | 0.9997 |
| XGBoost | 97.16% | 0.9715 | 0.9992 |
| LightGBM | 97.16% | 0.9715 | 0.9994 |
| CatBoost | 96.45% | 0.9644 | 0.9985 |
| Logistic Regression | 95.74% | 0.9577 | 0.9954 |

Random Forest (non-tuned) was selected as the production model based on highest combined accuracy and F1 performance across all evaluation metrics.

## Installation and Local Setup

### Prerequisites

- Python 3.9 or above
- pip

### Step 1: Clone the repository

```bash
git clone [Add GitHub Repository URL here]
cd addicsense
```

### Step 2: Install dependencies

```bash
pip install -r requirements.txt
```

### Step 3: Ensure model files are present

All files in the `models/` directory must be present before running the application. If they are missing, run the `AddiSence_ML.ipynb` notebook and download the generated `models/` folder.

### Step 4: Run the application

```bash
streamlit run app.py
```

The application will open in your default browser at `http://localhost:8501`.

## Input Features

The prediction form collects eleven features:

| Feature | Type | Range |
|---|---|---|
| Age | Numeric | 10 - 60 |
| Gender | Categorical | Male / Female |
| Academic Level | Categorical | High School / Undergraduate / Graduate |
| Country | Categorical | 110 countries |
| Average Daily Usage Hours | Continuous | 0 - 16 hrs |
| Most Used Platform | Categorical | 12 platforms |
| Affects Academic Performance | Binary | Yes / No |
| Sleep Hours Per Night | Continuous | 0 - 12 hrs |
| Mental Health Score | Integer | 1 - 10 |
| Relationship Status | Categorical | Single / In Relationship / Complicated |
| Conflicts Over Social Media | Integer | 0 - 20 |

---

## Output

Each prediction produces four outputs:

1. Addiction Level: Low, Moderate, High, or Severe with confidence percentage
2. Class Probabilities: Horizontal progress bars for all four classes
3. SHAP Explanation: Per-user feature contribution bar chart with Top 3 risk drivers
4. Recommendations: Personalised clinical advice and offline lifestyle alternatives

---

## Addiction Level Classification

| Level | Score Range | Description |
|---|---|---|
| Low | 1 - 3 | Healthy, balanced social media usage |
| Moderate | 4 - 5 | Some signs of over-reliance |
| High | 6 - 7 | Significant dependency patterns |
| Severe | 8 - 9 | Requires immediate behavioural intervention |

## Running the ML Pipeline

The full machine learning pipeline, data loading, EDA, preprocessing, model training, SHAP explainability, hyperparameter tuning, and model saving, is contained in `AddiSence_ML.ipynb`.

To retrain the models:

1. Upload the notebook and the dataset to Kaggle
2. Run all cells in sequence from Section 1 through Section 6.13
3. Download the generated `models/` folder
4. Replace the local `models/` directory with the downloaded files
